ID 和 CK 去哪拿？
1. 打开 51.la 注册账号（免费）
2. 添加应用，网址填你页面上线后的地址
3. 进「配置 → 统计代码」，里面有一行 LA.init({id:"xxx",ck:"xxx"})
4. 把两个值抄进来，确认代码里 autoTrack:true 是开着的（否则记不了链接点击）

两个前提：页面必须传到网上才有数据；事件上报每月有免费额度，个人页面一般用不完。

怎么让别人看到我的页面？
1. 点右上角「导出网页」，文件名保持 index 别改
2. 把这一个文件上传到免费静态托管
3. 拿到链接，就能像 VLink 一样到处发了

导出的文件是自带图片的单文件，不用打包文件夹，传一个就够。

托管平台怎么选？
推荐国内的（艾可秀 axureshow.com、腾讯云 CloudBase 等）：拖拽上传、不用 Git、国内打开快、微信里不弹警告。

不建议用 GitHub Pages：服务器在海外，国内打开慢；github.io 没备案，微信里会弹安全警告，访客得手动点「继续访问」，很劝退；而且它是共享域名，别人违规你可能跟着被封。

访问统计怎么办？
在上面的「访问统计」里填 51.la 的 ID 和 CK，导出时会自动带上。页面必须传到网上才有数据。
