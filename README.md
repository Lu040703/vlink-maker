# VLink 页面制作器（桌面版）

一个完全**本地免费**的聚合页制作工具，功能对齐 VLink 付费版：密码保护、无限模块、自定义样式，全部免费，不需要注册会员。

打包成 Windows 桌面程序（.exe），数据只存在你自己电脑上，不上传任何服务器。

## 下载桌面版

👉 [点这里下载最新版 exe](https://github.com/Lu040703/vlink-maker/releases/latest)
（zip 压缩包，解压后双击 `VLink页面制作器.exe` 即可使用，免安装）

## 它能做什么

| 功能 | 说明 |
|------|------|
| 9 种模块 | 链接按钮、二维码、封面大图、轮播图、商品卡、视频、音乐、文字段落、分组标题 |
| 无限数量 | 想放几个放几个，不像 VLink 免费版有数量限制 |
| 密码保护 | 导出的页面可设置密码，别人打开要先输密码 |
| 外观自定义 | 9 套预设主题 + 背景图/渐变/纯色 + 圆角/配色细调 |
| 访问统计 | 可选接入 51.la 统计（免费），追踪每个链接被点了几次 |
| 自动保存 | 编辑内容自动存本机，关掉再打开还在 |
| 备份迁移 | 一键备份成 .json，换电脑导入即可恢复 |
| 二维码生成 | 把页面网址转成二维码，方便扫码直达 |

## 怎么用

**桌面版（推荐）**：双击 `VLink页面制作器.exe`，直接开做。

**网页版**：用浏览器直接打开 `src/index.html` 也可以，功能一样（导出/导入走浏览器下载逻辑）。

三步上手：
1. 左边「页面内容」→ 填昵称简介、加模块、填链接
2. 左边「外观主题」→ 挑皮肤
3. 点「导出网页」→ 得到 `index.html` → 传到网上（艾可秀 axureshow.com、腾讯云 COS 等）即可分享

## 从源码运行 / 打包

环境要求：Node.js 18+

```bash
npm install          # 安装依赖（Electron 二进制国内下载慢可设 ELECTRON_MIRROR）
npm start            # 开发模式运行
npm run pack         # 打包出 dist/VLink页面制作器.exe（绿色版，免安装）
```

打包产物在 `dist/` 目录，把整个文件夹拷走就能用。

## 项目结构

```
vlink-desktop/
├── main.js              # Electron 主进程（窗口/菜单/系统文件对话框）
├── preload.js           # 安全桥：页面与系统之间的受控通道
├── package.json
└── src/
    ├── index.html       # 制作器本体（纯前端单文件，可独立当网页用）
    └── qrcode.min.js    # 本地化二维码库（离线可用）
```

> 提示：网页版 `src/index.html` 里导出文件用的是浏览器下载方式；桌面版会自动改用系统的「另存为」窗口，自己选保存位置。

## 边界说明（实话实说）

- **密码保护是防君子不防小人**：密码写在网页文件里，能拦住随手点进来的人，懂技术的能绕过，别放真正机密的内容。
- **访问统计需要页面托管到网上**才有数据，纯本地文件没人访问得到。
- 需要联网的功能只有：二维码模块里的"页面网址"、统计代码、以及导出页里你自己放的外部链接/图片。
