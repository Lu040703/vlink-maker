# 自建访问统计（三个文件，数据全在你自己服务器）

这三个文件配合 VLink 页面制作器 v1.0.7 的「自建统计」使用，替代 51.la 之类的第三方统计。

## 怎么用

1. 把 `hit.php`、`go.php`、`view.php` 三个文件传到你的网站目录（和页面 index.html 放一起最简单）
2. 打开 `view.php`，把里面的 `$PW` 改成你自己的密码
3. 在 VLink 制作器里：打开「访问统计」→ 方式选**自建统计** → 统计服务器地址**留空**（留空 = 和页面同一个网站）
4. 导出页面、上传到网站，完事

看数据：`https://你的域名/view.php?pw=你的密码`

## 三个文件分别干嘛

| 文件 | 作用 |
|---|---|
| `hit.php` | 记访问 + 记点击（一个 1 像素的图片，页面里自动插入） |
| `go.php` | 链接跳转记账。页面里的外链会被自动改成 `/go.php?u=原链接`，访客点链接时经过它，服务器记账后再跳走 |
| `view.php` | 数据后台。看访客、手机型号、点击记录、点击率 |

## 为什么要走 go.php 跳转

因为**抖音、微信的内置浏览器会拦截页面里的 JS 上报**，纯靠 JS 记点击会大量漏记。
go.php 是访客点链接时由**服务器**记账，不依赖手机上的脚本，所以记得住。

## 数据存在哪

存在网站目录下的 `.s_stats_9k2m7x.php` 文件里。开头有 `<?php exit('forbidden'); ?>` 保护头，
直接访问这个文件只会看到 forbidden，不会泄露数据。

## 安全提醒

- `view.php` 的密码默认是 `vlink2026`，**部署后第一件事就是改掉**
- 后台有防爆破：同一 IP 连错 8 次密码，锁定 10 分钟
- 记得定期备份 `.s_stats_9k2m7x.php`
